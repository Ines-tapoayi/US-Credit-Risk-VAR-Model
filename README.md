# US-credit-risk-var-model
## Overview
This project analyzes how US monetary policy affects bank credit and credit risk between 2000 and 2019.

The study relies on econometric modeling using:
- VAR
- SVAR
- Impulse Response Functions (IRF)
- Forecast Error Variance Decomposition (FEVD)
- Granger causality tests

## Objective
Study the transmission mechanism between:
- Federal Reserve interest rates
- Bank credit
- Economic activity
- Default rates

## Data
Variables used:
- FEDFUNDS
- GDP
- Total Bank Credit
- Default Rate

Sources:
- FRED
- TAC Economics

## Methodology
- Stationarity tests (ADF/KPSS)
- Differencing transformations
- VAR(1) estimation
- Structural VAR identification (Cholesky)
- IRF analysis
- FEVD decomposition

## Key Findings
- Monetary tightening reduces bank credit
- Credit expansion stimulates economic activity
- Default risk reacts with a delay
- Strong evidence of a credit channel

## Tools
- R
- Econometrics
- Time series
- VAR/SVAR modeling
- Macroeconomic analysis
